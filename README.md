# پروژه پورتفولیو شخصی با پنل مدیریت

## معرفی پروژه

این یک وبسایت پورتفولیوی شخصی با پنل مدیریت ساده است که به کاربران غیرفنی اجازه ميدهد بدون نياز به دانش کدنويسی، محتوا و ظاهر سايت خود را ويرايش کنند.

## اهداف پروژه

- طراحي وبسايت شخصي قابل ويرايش توسط خود کاربر
- مديريت محتوا بدون نياز به سرور
- ذخيره‌سازي اطلاعات در مرورگر کاربر
- طراحي واکنش‌گرا (ريسپانسيو)
- رابط کابري مدرن و جذاب

## امکانات

بخش معرفي: نمايش نام، عنوان، بيوگرافي و دکمه‌هاي اقدام
بخش آمار: نمايش آمار تجربه، پروژه‌ها و مشتريان
بخش درباره من: توضيحات کامل درباره توسعه‌دهنده
بخش مهارت‌ها: نمايش ليست مهارت‌ها با نوار پيشرفت
بخش پروژه‌ها: نمايش پروژه‌هاي انجام شده
بخش تماس: اطلاعات تماس و شبکه‌هاي اجتماعي
پنل مديريت: ويرايش تمام اطلاعات سايت

## شروع سريع

### پيش‌نيازها

- يک مرورگر مدرن (Chrome، Firefox، Edge، Safari)
- ويرايشگر کد (اختياري - براي تغيير کدها)

### نصب و اجرا

1. دانلود پروژه

git clone https://github.com/yourusername/your-repo.git
cd your-repo

2. اجراي پروژه

روش ساده: فايل index.html را در مرورگر باز کنيد
روش توسعه: از Live Server در VS Code استفاده کنيد

3. استفاده از پنل مديريت

- روي دکمه مديريت در گوشه پايين راست کليک کنيد
- اطلاعات خود را ويرايش کنيد
- روي ذخيره کليک کنيد
- صفحه را رفرش کنيد تا تغييرات اعمال شوند

## ساختار پروژه

پروژه/
├── index.html          ساختار اصلي سايت
├── style.css           طراحي و استايل‌ها
├── script.js           منطق و مديريت داده
├── images.jpg          عکس پروفايل
└── README.md           اين فايل

## تکنولوژي‌هاي استفاده شده

HTML5: ساختار صفحه
CSS3: طراحي و استايل‌دهي
JavaScript: منطق و مديريت داده
localStorage: ذخيره‌سازي اطلاعات
Git & GitHub: کنترل نسخه

## ويژگي‌هاي طراحي

- تم تيره مدرن: استفاده از رنگ‌هاي تيره با گراديانت‌هاي بنفش-صورتي
- طراحي ريسبانسيو: سازگار با دسکتاپ، تبلت و موبايل
- انيميشن‌هاي نرم: افکت‌هاي ظريف براي بهبود تجربه کابري
- المان‌هاي هندسي: دايره‌هاي چرخان، مربع‌ها و نقطه‌چين‌ها
- پنل مديريت مجزا: مودال با backdrop blur

## توسعه و سفارشي‌سازي

### تغيير رنگ‌ها

در فايل style.css، متغيرهاي زير را تغيير دهيد:

:root {
    --primary: #6C3CE1;
    --primary-dark: #5228B5;
    --primary-light: #8B6FE8;
    --bg: #0A0A0F;
    --text: #E8E8F0;
}

### افزودن بخش جديد

1. در index.html يک section جديد اضافه کنيد
2. در style.css استايل‌هاي مورد نياز را بنويسيد
3. در script.js داده‌هاي پيش‌فرض را به‌روز کنيد

## مشارکت

براي مشارکت در اين پروژه:

1. مخزن را Fork کنيد
2. يک برنچ جديد ايجاد کنيد: git checkout -b feature/امکان-جديد
3. تغييرات خود را اعمال کنيد: git commit -m 'افزودن امکان جديد'
4. برنچ را Push کنيد: git push origin feature/امکان-جديد
5. يک Pull Request ايجاد کنيد
